Use a navy desktop sidebar, a light working canvas, clear time comparison, a focused plan panel and compact mobile bottom navigation. Keep English copy and native single-choice radio semantics.

The early reference image's multiple-checkbox strip is superseded: **only one time slot can be selected**. Official opening hours and the Eupener service break must govern actual time options. Sample chart values, people and prices are illustrative.

The reference is a generated static design asset, not a screenshot of an implemented app. The user has authorized implementation of this direction. The client is a responsive web app; native mobile applications and home-screen widgets are excluded.
